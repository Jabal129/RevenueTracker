# تحصيل العقود — تطبيق أندرويد

نسخة الهاتف من نظام متابعة تحصيل إيرادات العقود: عقود وجدول أشهر لكل عقد، تحصيل مجمّع أو مقدّم بإثبات واحد، وإشعارات هاتف حقيقية عند تأخر التحصيل.

## الحصول على التطبيق (APK)

### الطريقة الأسهل: GitHub (بلا تثبيت أي شيء على جهازك)
1. أنشئ مستودعًا خاصًا على github.com وارفع إليه **كل** محتويات هذا المجلد، ومنها المجلد المخفي `.github`.
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (يعمل تلقائيًا أيضًا عند كل رفع).
3. بعد بضع دقائق افتح التشغيلة الناجحة ونزّل **tahseel-apk** من قسم Artifacts، وفكّ الضغط.
4. انقل `app-debug.apk` إلى الهاتف وثبّته (اسمح بالتثبيت من مصدر غير معروف عند السؤال).

### على جهازك
المتطلبات: Node 22+ و JDK 21 و Android Studio (Otter أو أحدث) مع Android SDK.

    bash build-android.sh        # على ويندوز: من Git Bash أو WSL

أو افتح المشروع في Android Studio بالأمر `npx cap open android` ثم Build ← Build APK.

## أول استخدام
1. افتح التطبيق وأضف عقدًا (يطلب الإذن بالإشعارات بعد حفظ أول عقد، اسمح به).
2. من ⚙ الإعدادات اضغط **إشعار تجريبي**؛ يصلك إشعار بعد 5 ثوانٍ.
3. استثنِ التطبيق من «توفير البطارية» في إعدادات الهاتف (شاومي، هواوي، أوبو، فيفو… توقف التطبيقات الخلفية وتؤخر التنبيهات).

## كيف تعمل الإشعارات
- محلية بالكامل: لا خادم ولا إنترنت. يجدولها التطبيق في نظام أندرويد نفسه، فتصل والتطبيق مغلق وبعد إعادة تشغيل الهاتف.
- **ملخص يومي** في الساعة المحددة (الافتراضي 9 صباحًا) ما دامت هناك أشهر متأخرة، ونصّه محسوب لحظة آخر فتح للتطبيق.
- **تنبيه في اليوم الذي يتأخر فيه كل شهر** غير محصّل (لأقرب 40 تاريخًا قادمًا).
- تُعاد الجدولة تلقائيًا عند فتح التطبيق وعند كل تعديل، فافتحه مرة كل شهر أو شهرين على الأقل.
- لمس الإشعار يفتح قائمة المتأخرات.

## البيانات والنسخ الاحتياطي
- كل البيانات والصور محفوظة على الهاتف داخل التطبيق فقط. حذف التطبيق يحذف بياناته.
- من ⚙ الإعدادات: **تصدير نسخة** (ملف JSON تشاركه إلى Drive أو واتساب أو البريد) و**استيراد نسخة** لاستعادتها أو للنقل إلى هاتف آخر.
- تُصغَّر الصور تلقائيًا (أطول ضلع 1400 بكسل) لتوفير المساحة.

## تجربة سريعة في المتصفح
افتح `www/index.html` في Chrome لترى الواجهة (بلا إشعارات).

## الفروق عن نسخة سطح المكتب
- الإثباتات صور فقط (التقاط بالكاميرا أو من المعرض)، بلا PDF.
- لا بريد إلكتروني؛ الإشعارات هنا هي إشعارات الهاتف.
- أندرويد فقط. آيفون يحتاج جهاز Mac وXcode وحساب مطوّر من Apple.
- ملف APK هنا للتجربة والاستخدام الداخلي (debug). النشر في Google Play يحتاج توقيعًا للإصدار.
